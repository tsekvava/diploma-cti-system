Threat Assessment: Howling Scorpius (Akira Ransomware)

Author: Yoav Zemah
Publication Date: December 2, 2024
Source: Unit 42, Palo Alto Networks


EXECUTIVE SUMMARY

Howling Scorpius, a ransomware group active since early 2023, operates the Akira ransomware-as-a-service (RaaS). The group consistently ranks among the top five most active ransomware operators and employs a double extortion strategy that significantly amplifies threat severity.

The group targets small to medium-sized businesses in North America, Europe, and Australia across diverse sectors including education, consulting, government, manufacturing, telecommunications, technology, and pharmaceuticals.

Unit 42 researchers have identified that Howling Scorpius maintains encryptors for Windows and Linux operating systems, with variants specifically designed for ESXi hosts. The group actively upgrades and enhances its toolkit, presenting an escalating risk to organizations.


HOWLING SCORPIUS OVERVIEW

First observed in March 2023, Akira implements a double extortion methodology: data exfiltration precedes encryption, allowing the threat actors to leak stolen data even if victims restore systems without paying ransom demands.

The group operates a Tor-based leak site displaying victim information and a separate negotiation site accessible via group-provided passwords. The leak site features a retro-green aesthetic and includes command functionality:
- The "leaks" command returns non-paying victims with .torrent file links
- The "news" command lists compromised companies dating to April 2023


TARGETED REGIONS

Analysis of Akira leak site data from March 2023 through October 2024 reveals:
- Most impacted country: United States
- Secondary targets: Canada, United Kingdom, Australia, Germany
- Pattern: Global distribution with North American concentration


TARGETED INDUSTRIES

Top affected sectors include:
1. Manufacturing
2. Professional and legal services
3. Wholesale/retail
4. Construction
5. Healthcare
6. Financial services
7. Education
8. Technology
9. Government
10. Telecommunications


TECHNICAL ANALYSIS: ATTACK LIFECYCLE

Initial Access

Howling Scorpius affiliates employ multiple vectors:

VPN Exploitation: Targets vulnerable VPN services lacking multi-factor authentication, often using credentials purchased from initial access brokers.

External-Facing Services: Remote Desktop Protocol (RDP) and other exposed services.

Spear Phishing Campaigns: Targeted email-based attacks.

Vulnerability Exploitation: Documented exploitation of Cisco products including CVE-2020-3259 and CVE-2023-20269.


Credentials Access

Local Credential Extraction:
- Mimikatz deployment
- LaZagne usage
- LSASS memory dumps via comsvcs.dll

Kerberoasting Attacks: Target service accounts and exploit credentials stored in memory.

Domain Control Extraction:
- SYSTEM registry hive copying
- NTDS.dit file exfiltration from domain controllers
- Complete user account and password hash enumeration

Compromised vCenter Exploitation:
- Domain controller virtual machine shutdown
- VMDK file copying to attacker-controlled VMs
- NTDT.dit and SYSTEM registry hive extraction


Persistence

The group creates new domain accounts to establish persistent access without requiring tool deployment. CISA documented creation of administrative domain accounts named "itadm."


Discovery and Lateral Movement

Network Reconnaissance:
- NetScan deployment
- Advanced IP Scanner usage
- PowerShell-based Active Directory enumeration
- Windows Net Commands for user/administrator discovery

Lateral Movement Methods:
- Remote Desktop Protocol (RDP)
- Server Message Block (SMB)
- Remote service creation
- Windows Management Instrumentation (WMI)


Defense Evasion

Bring Your Own Driver (BYOD):
The group abuses the Zemana antimalware driver to terminate antimalware-related processes, bypassing traditional security detection.

Antivirus Disablement:
- Windows Defender Real-Time Protection disabling via PowerShell
- EDR agent uninstallation

Bring Your Own VM:
Attackers create custom virtual machines with disabled security tools, mount hypervisor storage drives, and execute ransomware within the new VM to circumvent host security controls.


Exfiltration

Data exfiltration methodology combines multiple tools:
- WinRAR: File compression
- WinSCP/RClone/FileZilla: File transfer
- FTP Protocol: Primary exfiltration transport

Example command observed:
"C:\\Program Files\\WinRAR\\WinRAR.exe" a -ep1 -scul -r0 -iext -imon1 -- . "[REDACTED]\\Company\\[REDACTED]" [REDACTED]\\Company\\HR "[REDACTED]\\Company\\Human Resources Management - HR"


AKIRA RANSOMWARE ENCRYPTORS

Ransom Note

Upon successful encryption, the malware creates "akira_readme.txt" containing:
- Leak site links
- Negotiation site information
- Unique victim code for communicating with attackers


Windows Variant

Execution:
The variant attempts to delete shadow copies using:
powershell.exe -Command "Get-WmiObject Win32_Shadowcopy | Remove-WmiObject"

Command-Line Arguments:
- -p/--encryption_path: Root directory for encryption
- -s/--share_file: Targeted network drive path
- -n/--encryption_percent: Data encryption percentage per file
- --fork: Child process creation
- -l: Drive list logging
- -localonly: Remote drive exclusion
- -e/--exclude: File exclusion specification

Encryption Implementation:
- Algorithm: ChaCha20 for file content
- Key management: ChaCha20 key encrypted with hard-coded RSA public key
- Support: Full and partial encryption modes

Vulnerability Response:
Avast published a decryptor in June 2023 exploiting an encryption scheme vulnerability. Unit 42 identified samples indicating Howling Scorpius patched this vulnerability within three days of public disclosure.

February 2024 Updates:
- KCipher2 algorithm implementation alongside ChaCha20
- Encrypted file extension: .akira


Megazord Variant

Emerged August 2023 as a Rust-written strain with:
- Similar ransom note content referencing Akira negotiation sites
- File extension: .powerranges
- Ransom note filename: powerranges.txt
- Password requirement via --id argument

Command Execution:
Megazord terminates extensive lists of services and processes that could impede encryption.

March 2024 Updates:
- --proc argument: Disable process/service termination
- --dirs argument: Ignore blocklisted directories

Operator Variation:
One unique sample contained a different ransom note with Telegram contact information, suggesting possible use by different threat actors, though this remains unconfirmed.


Linux/ESXi Variant

Design Assessment:
Internal strings and ESXCLI command execution indicate initial design for ESXi systems.

Logging Disablement:
/bin/sh -c 'esxcli system syslog config set --logdir=/tmp'
/bin/sh -c 'esxcli system syslog reload'
/bin/sh -c 'esxcli system coredump file set --unconfigure'

Command-Line Arguments:
- -p/--encryption_path: Root directory for encryption
- -s/--share_file: Targeted network drive path
- -n/--encryption_percent: Data encryption percentage per file
- --fork: Child process creation

Encryption Implementation:
- Symmetric algorithms: AES, CAMELLIA, DES, IDEA
- RSA public key wrapping of symmetric keys
- Full and partial encryption support

Targeted File Extensions:
.vmdk, .vmem, .vmx, .log, .vswp, .vmsd, .vmsn


Akira_v2 (Linux/ESXi Rust Variant)

Released April 2024 with expanded capabilities.

New Arguments:
- --id: Password requirement for execution
- --vmonly: VM-only encryption capability
- --stopvm: Virtual machine shutdown functionality

VM Shutdown Command:
vim-cmd vmsvc/getallvms | tail -n +2 | awk '{system("vim-cmd vmsvc/power.off " $1)}'

Targeted Extensions:
.vmdk, .vmem, .vmx, .log, .vswp, .vmsd, .vmsn

Ransom Note:
Filename changed to akiranew.txt with .akiranew file extension, still referencing original negotiation site.

PROTECTION AND MITIGATION

Palo Alto Networks provides defense through:

- Advanced WildFire: Cloud-delivered malware analysis identifying known samples
- Cortex XDR/XSIAM: Behavioral threat protection, machine learning-based detection, credential-based attack identification
- Anti-Ransomware Module: Encryption-based activity targeting, pre-data-loss activity halting
- Cortex Xpanse: Internet-exposed RDP and VPN detection


MITRE ATT&CK TACTICS AND TECHNIQUES

Initial Access:
- T1190 - Exploit Public-Facing Application (CVE-2020-3259, CVE-2023-20269 on Cisco VPN)
- T1078 - Valid Accounts (credentials from initial access brokers)
- T1566 - Phishing (spear phishing campaigns)
- T1133 - External Remote Services (RDP, VPN)

Credential Access:
- T1003.001 - OS Credential Dumping: LSASS Memory (comsvcs.dll)
- T1003.002 - OS Credential Dumping: Security Account Manager (SYSTEM hive)
- T1003.003 - OS Credential Dumping: NTDS (NTDS.dit exfiltration)
- T1558.003 - Steal or Forge Kerberos Tickets: Kerberoasting
- T1555 - Credentials from Password Stores (LaZagne)

Persistence:
- T1136.002 - Create Account: Domain Account (itadm)

Discovery:
- T1046 - Network Service Scanning (NetScan, Advanced IP Scanner)
- T1018 - Remote System Discovery (PowerShell AD enumeration)
- T1087 - Account Discovery (Windows Net Commands)

Lateral Movement:
- T1021.001 - Remote Services: Remote Desktop Protocol
- T1021.002 - Remote Services: SMB/Windows Admin Shares
- T1543 - Create or Modify System Process (remote service creation)
- T1047 - Windows Management Instrumentation

Defense Evasion:
- T1562.001 - Impair Defenses: Disable or Modify Tools (Windows Defender, EDR)
- T1068 - Exploitation for Privilege Escalation (Zemana driver abuse / BYOD)
- T1564.006 - Hide Artifacts: Run Virtual Instance (Bring Your Own VM)

Exfiltration:
- T1560.001 - Archive Collected Data: Archive via Utility (WinRAR)
- T1048.003 - Exfiltration Over Alternative Protocol: Exfiltration Over Unencrypted Non-C2 Protocol (FTP)
- T1567 - Exfiltration Over Web Service (WinSCP, RClone, FileZilla)

Impact:
- T1486 - Data Encrypted for Impact (ChaCha20 + RSA, AES/CAMELLIA/DES/IDEA + RSA)
- T1490 - Inhibit System Recovery (shadow copy deletion)
- T1489 - Service Stop (Megazord terminates services/processes before encryption)
